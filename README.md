# PHDM

## NotebookLM MCP Server Integration

Ce projet intègre le serveur MCP NotebookLM pour permettre aux agents IA d'accéder à vos connaissances NotebookLM sans hallucinations.

### 🚀 Installation Rapide

```bash
# Exécuter le script d'installation
./setup_mcp.sh
```

### 📖 Documentation Complète

Pour des instructions détaillées sur la configuration et l'utilisation, consultez [MCP_SETUP.md](./MCP_SETUP.md)

### 🔑 Configuration Requise

1. Configurez la variable d'environnement `NOTEBOOKLM_COOKIE`
2. Redémarrez votre IDE
3. Commencez à utiliser NotebookLM avec vos agents IA

Pour plus de détails, voir la [documentation complète](./MCP_SETUP.md).
